# Public Portfolio Guidelines

This repository is intended to demonstrate capability without exposing proprietary implementation details.

## Safe to publish

- High-level product descriptions
- Sanitized screenshots
- Fictional data
- High-level architecture
- Business problems and outcomes
- Public technology categories
- Generic workflow descriptions

## Keep private

- Source code for proprietary systems
- Prompt libraries
- Agent instructions
- Detailed orchestration logic
- Scoring formulas
- Internal algorithms
- Database schemas
- Customer integrations
- Customer names or data
- Real financial data
- Pricing logic
- Credentials, keys, tokens, and secrets
- Proprietary company documents
- Detailed commercial roadmap

## Before each public update

Ask:
1. Does this reveal how the system works in a way a competitor could reproduce?
2. Does it expose confidential or company-owned information?
3. Does it expose implementation details that are not necessary to prove capability?
4. Could the same proof be shown using sanitized data or a higher-level description?

If yes, keep that material private.
